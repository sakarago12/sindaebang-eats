# 신대방역 1km 맛집

2호선 신대방역 반경 약 1km 안의 식당 57곳을 다이닝코드·구글 지도 별점, 후기 요약, 도보 거리로 찾아볼 수 있는 한 장짜리 페이지입니다.

- 페이지: `index.html` (HTML 파일 하나, 별도 빌드 없음)
- 별점·리뷰 수: 다이닝코드, 구글 지도 사용자 평가 (2026-11-06 조회 기준)
- 후기 요약은 원문을 옮기지 않고 짧게 정리한 것입니다.

## 수정하는 법

1. `index.html`을 고칩니다. 가게 목록은 파일 아래쪽 `const D=[...]`, 구글 별점은 `const G={...}`에 있습니다.
2. 변경 내용을 올립니다.
   ```bash
   git add .
   git commit -m "설명"
   git push
   ```
3. 1~2분 뒤 GitHub Pages 주소에 반영됩니다.
